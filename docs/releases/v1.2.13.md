# Divoom v1.2.13

Музыка с компьютера — на экране Divoom MiniToo.
Первый публичный релиз проекта **Divoom Music Display** для Windows x64.

## Скачать и запустить

1. Скачайте `Divoom-v1.2.13-windows-x64.zip` и распакуйте в отдельную папку.
2. Сопрягите MiniToo с Windows по Bluetooth.
3. Запустите `Divoom.exe`, выберите устройство и нажмите **Подключиться**.

Python для готовой версии не нужен. USB используется для звука/питания;
изображение передаётся по Bluetooth Classic RFCOMM.

## В этом релизе

- Название, исполнитель и обложка из Windows SMTC, без входа в музыкальный аккаунт.
- Фон в цветах обложки, часы и значок приложения при отсутствии обложки.
- Постраничное отображение длинных названий по две строки.
- Настраиваемые размер кадра, число цветов и число кадров.
- Предпросмотр, состояние соединения, выбор MiniToo и интерфейс RU/EN.
- Тёмное оформление со скруглениями и подсказками.
- Debug для ручного тестирования LOADING с заданным объёмом загрузки.

## Совместимость и ограничения

Проверена модель **Divoom MiniToo, 160×128**; другие модели пока не заявлены.
Обложки доступны, если проигрыватель передаёт их Windows. Для длинных названий
загружается вся анимация: лимит на один кадр не исключает LOADING.
Часы показывают московское время. Рекомендуемый старт: 24 КБ, 128 цветов, 1–2 кадра.
Сборка не подписана цифровым сертификатом.
