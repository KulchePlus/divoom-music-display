# Divoom v1.3.5

Автоподключение и события Bluetooth Windows.

## Что нового

- При обычном запуске и автозапуске в трее приложение подключается к последнему успешно использованному устройству, если оно доступно в Windows.
- Список устройств обновляется по событиям Windows без периодического опроса Bluetooth.
- Если знакомое устройство подключилось позже, приложение автоматически устанавливает соединение с экраном.
- Кнопка **Отключиться** приостанавливает автоматическое подключение до ручного подключения или перезапуска приложения.
- При обновлении со старой версии используется ранее сохранённое устройство. Настройки сохраняются.
