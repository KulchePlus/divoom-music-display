# Divoom v1.3.3

## Новое

- Закрытие окна на крестик скрывает приложение в системный трей. Обновление экрана продолжается в фоне при активном соединении.
- Через меню значка можно открыть окно или полностью выйти из приложения.
- Переключатель **Запускать при загрузке Windows**: автозапуск для текущего пользователя при входе в систему, сразу в трее.
- Автозапуск выключен по умолчанию. Для отключения выключите переключатель.

## Скачать и обновить

[**Divoom.zip**](https://github.com/KulchePlus/divoom-music-display/releases/download/v1.3.3/Divoom.zip) — приложение для Windows x64; внутри **Divoom.exe**.
Можно установить через кнопку проверки обновлений. Настройки сохраняются.
Перед ручной заменой EXE выберите **Выйти** в меню трея: крестик больше не завершает процесс.

После переноса папки приложения включите автозапуск заново, чтобы обновить путь.
Автозапуск не подключает устройство автоматически: подключитесь через основное окно.

Дополнительный архив с версией в имени оставлен для совместимости с обновлением из v1.3.1.
Контрольные суммы — в SHA256SUMS.txt.

Поддержка отправки изображения: Divoom MiniToo 160×128, Bluetooth Classic RFCOMM.
