# Divoom v1.3.2

Пиксельный экран ожидания, удобные настройки и обновлённый список Bluetooth-устройств.

## Скачать

**[Divoom.zip](https://github.com/KulchePlus/divoom-music-display/releases/download/v1.3.2/Divoom.zip)** — готовое приложение для Windows x64.
Распакуйте архив и запустите **Divoom.exe**. Python не требуется.

## Что нового

- **Пиксельная ночь с котом**, когда в Windows нет медиасессии: актуальные часы, дата, мерцание звёзд и фонаря.
- **Три кадра анимации с соблюдением настроек.** Максимум 1 — статичный экран; 2 — два кадра; 3 и больше — три. Лимит КБ и палитра применяются к каждому кадру.
- **Параметры передачи свёрнуты по умолчанию.** Скруглённый блок плавно раскрывается и закрывается по заголовку.
- **Все подключённые Bluetooth Classic и LE устройства** без фильтра по названию и старых записей кэша. Переименованный MiniToo тоже доступен.
- **JPEG начинается с качества 100**, снижение выполняется только для соблюдения лимита кадра.
- Версия **v1.3.2** отображается в нижнем правом углу рядом с Debug.
- Основной архив теперь называется **Divoom.zip**, EXE внутри — **Divoom.exe**.

## Обновление

В v1.3.1 нажмите **Проверить обновления**, затем **Установить v1.3.2 и перезапустить**.
При ручной установке закройте приложение и замените EXE в прежней папке.
Локальные настройки, выбранное устройство и кэш сохраняются.

Дополнительный архив `Divoom-v1.3.2-windows-x64.zip` — идентичная копия для совместимости
с автообновлением v1.3.1. Для ручной загрузки выбирайте **Divoom.zip**.
`SHA256SUMS.txt` содержит контрольные суммы обоих архивов.

## Совместимость

Windows 10 / 11 x64. Отправка изображения проверена на **Divoom MiniToo, 160×128**.
Наличие других Bluetooth-устройств в списке не означает поддержки их протокола.
При паузе медиасессии остаётся карточка трека; экран ожидания появляется при отсутствии медиасессии.
Часы показывают московское время. Лимит действует на кадр, вся анимация загружается целиком;
при первичной загрузке возможен LOADING. Качество JPEG пока одинаковое для всех кадров клипа.
