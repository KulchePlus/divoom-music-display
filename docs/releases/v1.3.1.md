# Divoom v1.3.1

Обновления приложения через GitHub Releases: проверка при запуске, установка по кнопке и сохранение настроек.

## Что нового

- **Переключатель «Автообновления».** Выбор сохраняется между запусками.
- **Одна проверка при открытии.** Периодических запросов нет; включение переключателя во время работы не запускает проверку.
- **Ручная проверка** доступна независимо от переключателя.
- **Установка новой версии по кнопке:** загрузка ZIP, проверка SHA-256 и перезапуск.
- **Резервная копия** `Divoom.previous.exe`; при ошибке замены возвращается прежний EXE.
- **Сохранение настроек**, выбранного устройства, логов и кэша при обновлении.
- Исправлена упаковка SSL-данных; готовый EXE проверяется на поддержку HTTPS в GitHub Actions.
- Исправлена компоновка блока обновлений в небольшом окне; добавлены переводы RU/EN.

## Как перейти на v1.3.1

1. Скачайте `Divoom-v1.3.1-windows-x64.zip` ниже.
2. Закройте приложение и распакуйте новую версию в прежнюю папку с заменой `Divoom.exe`.
3. Запустите приложение. Сохранённые настройки останутся на месте.

В v1.2.13 механизма обновления ещё нет, поэтому первый переход выполняется вручную.
Начиная с этой версии новые стабильные релизы можно устанавливать из приложения.
Скачивание и установка начинаются только после нажатия соответствующей кнопки.

## Совместимость

Windows 10 / 11 x64, Divoom MiniToo 160×128. USB используется для звука и питания,
экран обновляется по Bluetooth Classic RFCOMM. Обложки зависят от метаданных проигрывателя.
Часы показывают московское время. Сборка не подписана цифровым сертификатом;
SHA-256 подтверждает целостность загрузки и не заменяет подпись издателя.
Автоматический откат при сбое запуска уже установленной новой версии пока не предусмотрен.
