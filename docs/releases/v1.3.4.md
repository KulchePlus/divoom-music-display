# Divoom v1.3.4

Исправление перезапуска приложения после обновления.

## Исправлено

Новая версия запускается как независимый процесс PyInstaller и не использует удалённую временную папку прежнего экземпляра. Это устраняет ошибку загрузки `python312.dll` после обновления.

Добавлен тест передачи независимого окружения помощнику установки; готовый EXE проверен с несуществующей папкой старого процесса.

## Скачать

[**Divoom.zip**](https://github.com/KulchePlus/divoom-music-display/releases/download/v1.3.4/Divoom.zip) — Windows x64, внутри **Divoom.exe**. Настройки сохраняются.

**При переходе со старой версии помощник обновления ещё старый.** Если после установки снова появится ошибка Python DLL, закройте сообщение и запустите Divoom.exe вручную. Следующие обновления из v1.3.4 используют исправленный помощник. Альтернатива — закрыть приложение через «Выйти» в трее и вручную заменить EXE из ZIP.

Дополнительный архив со старым именем сохранён для совместимости с v1.3.1. Контрольные суммы — SHA256SUMS.txt.
