# Changelog

## Unreleased

- Исправлен перезапуск после обновления: новый EXE не наследует временную папку старого PyInstaller-процесса.

## [1.3.3] — 2026-10-29

- Переключатель автозапуска при входе в Windows; запуск в трее без открытия окна.
- Закрытие на крестик скрывает приложение в трей; меню значка позволяет открыть окно или завершить работу.

## [1.3.2] — 2026-10-25

- Основной архив релиза — Divoom.zip; автообновление поддерживает новое и прежнее имя.
- Подбор JPEG начинается с качества 100 и снижается только для соблюдения лимита кадра.
- Экран без медиасессии: пиксельная ночь с котом, живыми часами и датой; три кадра мерцания звёзд и фонаря с соблюдением максимума кадров.
- Раскрытие и сворачивание параметров передачи анимированы с плавным изменением высоты.
- «Параметры передачи» сворачиваются по нажатию на заголовок и закрыты по умолчанию.
- Рамка «Параметры передачи» скруглена в общем стиле интерфейса.
- Список устройств использует подключённые Bluetooth Classic/LE устройства Windows без фильтрации названия и старых записей кэша.
- Версия приложения перенесена из шапки в нижний правый угол рядом с Debug.


## [1.3.1] — 2026-10-24

- Переключатель автоматической проверки только при запуске с сохранением выбора.
- Фоновая и ручная проверка стабильных GitHub Releases.
- Установка по кнопке с проверкой SHA-256, резервной копией EXE и перезапуском.
- Сохранение настроек и возврат старого EXE при ошибке замены.
- Проверки выбора версии, целостности архива и Windows-помощника установки.
- Исправлена упаковка дополнительных данных SSL; HTTPS проверяется в готовом EXE на CI.
- Исправлена компоновка нижнего блока: элементы обновления остаются видимыми.

## [1.2.13] — 2026-10-24

Первый публичный релиз Divoom Music Display.

- Текущая музыка из системных медиасессий Windows: название, исполнитель, обложка.
- Экран 160×128 с фоном в цветах обложки, часами и градиентным разделителем.
- Значок проигрывателя при отсутствии обложки; проверены Яндекс Музыка и Firefox.
- Перелистывание длинных названий целыми страницами по две строки.
- Лимит на кадр, палитры 8–256 цветов и ограничение числа кадров.
- Выбор сохранённого в Windows MiniToo и запоминание последнего выбора.
- Тёмный интерфейс со скруглениями, предпросмотром, статусом и RU/EN.
- Ручное тестирование размера передачи через Debug.
- Переносимая сборка Windows x64 и автоматические релизы GitHub Actions.

Версии приложения следуют Semantic Versioning: `MAJOR.MINOR.PATCH`.
Предыдущие локальные итерации не публиковались как GitHub-релизы.
